## Integrations — LOCAL STUBS ONLY (critical rule, from Queue #1's proven pattern)
- **Lead form → "Google Sheet":** `js/app.js` appends a row `{timestamp, page, name, phone, interest, message, ref}` to a localStorage sheet log (`lp_sheet_log`) that mimics a Sheet row. Every form carries the honest note: in production this posts to the client's Google Sheet. Confirmation issues a deterministic reference `LP-DEMO-####` and shows the exact summary.
- **GA4 + Meta Pixel:** config objects in `js/logic.js` hold DEMO placeholder IDs only (`G-DEMO-000000`, `DEMO-PIXEL-000000`); a local `track()` records `page_view`, `lead_submit` and `whatsapp_click` events (GA4-style + Pixel-style pair per event) to a local event log (`lp_event_log`). The battery asserts **zero live endpoints in source** (no googletagmanager.com, no connect.facebook.net, no google-analytics.com, no gtag call).
- **WhatsApp:** real `wa.me` links with per-page prefilled offer text; clicks are recorded synchronously to the event log — firing recorded in the flow run for all three pages (lesson 21).
- **Logs viewer (`logs.html`):** renders both local logs in tables with counts and a clear-logs control — the cross-surface proof surface (lesson 30): the flow run submits on all three pages, clicks WhatsApp on all three, then shows all of it on the logs page (3 sheet rows, 20 events).
